# Combination Crafter

**Packaged Core:** <ItemLink id="ae2ltpp:ec_combination_packaged_core" />
**Mod:** Extended Crafting

Automatically performs Combination Crafting. Place the provider against the **Combination Crafting Core**. Encode the corresponding **processing pattern**, and the result is retrieved when crafting finishes.

## Requirements

* Surround the core with **Pedestals** within a 7×7 area on the **same horizontal level** as the core.
* The core needs power. The provider does not check its energy level, so if a craft becomes stuck, check your power supply.
* Before starting, the core slot and the pedestals used for this craft must be empty.
