# Alfheim Portal

**Packaged Core:** <ItemLink id="ae2ltpp:botania_alfheim_portal_packaged_core" />
**Mod:** Botania

Automatically performs Elven Trade recipes through the Alfheim Portal. Place the provider against the Alfheim Portal's core block and encode the corresponding **processing pattern**; the provider automatically retrieves the result.

## ⚠ Notes

* The trade only runs while the **portal is open** (activated). Make sure it stays open during automation.
* If a trade has multiple outputs, the pattern must declare every output stack.
* One trade is processed per request. For volume, submit the pattern multiple times rather than expecting
  a single large batch.
