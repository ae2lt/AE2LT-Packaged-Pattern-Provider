# 通用机械：更多机器 — 大型机器

**所需封包核心：** <ItemLink id="ae2ltpp:mekmm_packaged_core" />
**来源模组：** Mekanism: More Machines（通用机械：更多机器）

这个封包核心是通用的，一个封包核心即可驱动该模组**全部**大型多方块机器。
搭好机器，把供应器贴着它的放置，并装入封包核心，并编写相应**处理样板**，供应器会自动识别面对的机器类型，并将合成产物回收。
* 样板中的物品、流体与化学品输入会自动送到对应端口。

`编者注：目前未经较为精准的测试，实际无需放在所谓的控制器方块附近，只需紧挨着大型机器，若不行，请尝试链接机器顶部/底部中央方块(无线版)或者贴着这些部位使用(普通版)，等待后续测试中修正文案`

## 覆盖的机器

* 大型化学注入机
* 大型电解分离机
* 大型反质子核合成机
* 大型旋转冷凝机
* 大型太阳能中子活化机
* 大型颜料混合机

## 注意事项

* 机器运转仍需自身的**能量**，请保持能量供应充足。
