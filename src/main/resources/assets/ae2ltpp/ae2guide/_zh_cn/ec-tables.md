# 工作台（基础 / 高级 / 精英 / 终极）

**所需封包核心：** <ItemLink id="ae2ltpp:ec_basic_table_packaged_core" />
<ItemLink id="ae2ltpp:ec_advanced_table_packaged_core" />
<ItemLink id="ae2ltpp:ec_elite_table_packaged_core" />
<ItemLink id="ae2ltpp:ec_ultimate_table_packaged_core" />
**来源模组：** Extended Crafting（合成拓展）

自动完成合成拓展的四种工作台。
把供应器贴着工作台放置，编写相应**处理样板**，合成完成后产物与剩余物会一并返回。

## ⚠ 高阶封包核心向下兼容

高阶封包核心继承低阶封包核心的功能：
终极工作台封包核心可处理终极/精英/高级/基础配方，
精英工作台封包核心可处理精英/高级/基础配方，依此类推。

## 注意事项

* 自动合成期间，工作台的合成格必须**空置**，也不要同时用手动合成。
