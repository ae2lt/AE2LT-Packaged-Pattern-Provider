# 魔力池

**所需封包核心：** <ItemLink id="ae2ltpp:botania_mana_pool_packaged_core" />
**来源模组：** Botania（植物魔法）

自动完成魔力池的魔力注入。把供应器贴着魔力池放置，将配方做成样板，供应器会将合成后的产物回收。

## ⚠ 魔力与催化方块

* 每次合成池中都要有足够的**魔力**
* 部分配方需要在**池子下方放置催化器**（例如 炼金催化器 或 炼造催化器）。请按配方要求放上正确的催化方块，魔力池会根据下方方块选择对应的配方。
* 你仍需多台供应器与魔力池，因为有无催化器的部分配方存在冲突。
