# Empowerer

**Packaged Core:** <ItemLink id="ae2ltpp:aa_empowerer_packaged_core" />
**Mod:** Actually Additions

Automatically performs Empowering recipes. Place the provider against the Empowerer and encode the corresponding **processing pattern**.
The provider distributes the items to the appropriate positions and retrieves the result when crafting finishes.

## Structure requirements

* Build the complete multiblock structure according to the mod's instructions.
* The Display Stands need power, just as they do for manual Empowering.
* Before starting, the Empowerer and all 4 Display Stand item slots must be empty.
